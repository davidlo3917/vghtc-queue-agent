PSEUDOCODE ・ ALGORITHM 1

Agent 的監看迴圈

01: wait until session appears ▷ 提前訂閱

02: while session active:

03: st ← latest state (cur_seq, waiting, notice)

04: if st.cur_seq ≥ N: notify("已叫到"); record; break

05: (W20, W50, W80) ← Predict(features) ▷ Alg. 2

06: E ← DetectEvents(代診 | 延誤 | 速度異常 | 預測變動>15)

07: if E ≠ ∅ and cooldownOK: notify(Explain(E))

08: leaveAt ← now + W20 − travel − buffer

09: if not arrived and now ≥ leaveAt: notify("該出門了")

10: sleep(60 s)

11: if ended and cur_seq < N: notify("診次已結束")

每輪兩件事

狀態變了就重算、判斷事件；不管變沒變都檢查出門時間

只在該說話時說話

事件觸發 + 冷卻，不是每分鐘推播

出門用 W20

偏早的估計，寧可早到不要過號
