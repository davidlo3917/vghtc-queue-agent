Model 的預測

01: gap ← N − cur_seq ▷ 號碼差

02: onsite ← waiting ▷ 現場人數

03: rToday ← rolling rate (30 min) ▷ 今日每號分鐘

04: rHist ← doctor history rate ▷ 退回同科、全院

05: nClass ← ClassifyNotice(notice) ▷ LLM，退回關鍵字

06: x ← (gap, onsite, rToday, rHist, 時段, 距截止, nClass, …)

07: if model trained:

08: (W20, W50, W80) ← LightGBM_quantile(x)

09: else: ▷ baseline

10: W50 ← gap · r; W20 ← 0.7·W50; W80 ← 1.5·W50

11: return (W20, W50, W80)
