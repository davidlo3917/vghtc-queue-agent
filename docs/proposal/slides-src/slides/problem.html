C. PROBLEM ・ 真正要解決的問題

病人要的是兩個決策，不是一個數字

決策 1

我的號碼大約幾點會被叫到？

答案是一個時間區間，不是一個點；低估比高估更傷人

決策 2

我幾點該出門，才能不過號、也不空等？

風險方向相反：晚出門的代價是過號，比多等幾分鐘嚴重

答案會隨時間改變，所以需要的是 Agent，不是一次性的 Model

醫師臨時請假、速度突然變慢、長者與過號者插入，都會讓半小時前的估計失效。系統必須持續監看、在狀態改變時重新推理、在對的時間主動提醒。形式化：給定診間、午別與號碼 N，在任一時刻輸出 N 的叫號時間區間與出門建議，並在事件發生時更新。

Domain AI Agent 問題定義

這頁是「不要只做一個 model」的回答。model 回答還要幾分鐘；agent 回答你現在該不該出門、為什麼、有多確定，而且會主動盯著變化。
